# Changelog

## v1.0 - 2026-07-13

Manuscript-associated DTDisMind release for:

> DTDisMind: a confidence-annotated drug-target-disease atlas integrating ensemble target inference and ncRNA context

Public platform:

- https://tmliang.cn/dtdismind/

Release snapshot:

- 29,175 network nodes and 109,631 network edges.
- 9,912 high-confidence DTI candidates selected by the Core5+2 rule.
- 5,602 high-confidence core DTD triplets used for manuscript analyses.
- 10,960 expanded web-layer DTD triplets exposed by the website.
- 14,377 ncRNA nodes retained as a regulatory context layer.

Repository changes:

- Aligned public documentation, deployment examples, and static build assets with the DTDisMind name.
- Updated production URL references to `/dtdismind/`.
- Added an MIT License for source code.
- Added explicit source-database licensing notes for third-party data, including DrugBank-derived records.
- Normalized release tag metadata to the maintainer GitHub noreply identity.
